# Harry Potter characters

Небольшое React-приложение для просмотра персонажей вселенной Harry Potter.

## Возможности

- поиск персонажа по имени;
- фильтрация по факультету;
- очистка выбранных фильтров;
- адаптивная сетка карточек;
- отображение основных данных персонажа.

## Запуск

```bash
npm install
npm run dev
```

Для проверки production-сборки:

```bash
npm run build
```
